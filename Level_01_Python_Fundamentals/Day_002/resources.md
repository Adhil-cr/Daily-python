## Functions Learned Today

### print()

Displays output.

Example:

```python
print("Hello")
```

---

### input()

Reads user input.

Example:

```python
name = input("Enter your name: ")
```

---

### int()

Converts a value to an integer.

Example:

```python
number = int("25")
```

---

### float()

Converts a value to a floating-point number.

Example:

```python
price = float("19.99")
```

---

### bool()

Converts a value to a Boolean.

Example:

```python
bool(1)
bool(0)
```
