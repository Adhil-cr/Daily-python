## Helpful Examples

Age Validation

```python
if age < 0 or age > 120:
    print("Invalid Age")
```

Voting Eligibility

```python
if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")
```

Grade Calculation

```python
if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
else:
    print("F")
```
