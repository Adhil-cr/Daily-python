5.strip()
Ans : - It is a built in method used to remove from leading(beginning) and trailing (ending) whitespace or specified character from a string
      - Syntax : variablename.strip() it removes whitespace from Leading and trailing
      - Example : name = " adhil "
                  name.strip()  
                  output : adhil 
      - Common uses : - remove whitespace from string
                      - remove specified characters from string
                      - validate empty input
